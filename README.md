# DnD-AI-Librarian (D&D Knowledge Keeper)

DnD-AI-Librarian — это интеллектуальный ассистент для игроков и мастеров настольно-ролевой игры Dungeons & Dragons (D&D 5e). 
Он представляет собой RAG-систему (Retrieval-Augmented Generation), которая позволяет задавать вопросы по правилам игры на естественном языке и получать точные ответы со ссылками на первоисточники.

В качестве базы знаний выступают официальные переводы правил, статей и механик с ресурса [dnd.su](https://dnd.su).

## Стек технологий
- **Интерфейс:** Streamlit
- **Векторная база данных:** Qdrant (локальная)
- **Модели:** Groq API (LLM для ответов и перефразирования), SentenceTransformers (Dense-эмбеддинги), FastEmbed (Sparse-эмбеддинги / BM25)
- **Инфраструктура:** Docker, Docker Compose

## Как запустить

### Способ 1: С помощью Docker (Рекомендуемый)
Для запуска вам понадобится установленный Docker и ключ `GROQ_API_KEY`.

1. Создайте файл `.env` в корне проекта и добавьте ваш ключ:
   ```env
   GROQ_API_KEY=ваш_ключ
   ```
2. Запустите сборку и старт приложения:
   ```bash
   docker-compose up --build -d
   ```
   *(При первой сборке векторная база данных сгенерируется автоматически прямо внутри образа).*
3. Откройте браузер по адресу: `http://localhost:8501`

### Способ 2: Production (Через готовый образ с Docker Hub)
Если вы хотите развернуть готовое приложение без локальной сборки исходников, воспользуйтесь продакшен-конфигом:
1. Запустите контейнер, указав нужный файл конфигурации:
   ```bash
   docker-compose -f docker-compose.prod.yml up -d
   ```
   *(Флаг `-f` должен стоять строго **до** команды `up`).*
2. Откройте браузер по адресу: `http://localhost:8501`

### Способ 3: Локально (Без Docker)
1. Установите зависимости в виртуальное окружение:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
2. Убедитесь, что у вас есть `.env` файл с `GROQ_API_KEY`.
3. Сгенерируйте векторную базу (если еще не создана):
   ```bash
   python main_ingest.py
   ```
4. Запустите Streamlit:
   ```bash
   streamlit run app.py
   ```
